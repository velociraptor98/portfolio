# Adwityaa Jha — Portfolio

Personal portfolio of **Adwityaa Jha**, showcasing work in business strategy, product, and project management. Built with [Next.js](https://nextjs.org/), [Three.js](https://threejs.org/), and [Framer Motion](https://www.framer.com/motion/).

🔗 Live site: [adwityaajha.com](https://adwityaajha.com)

> Design adapted from [Hamish Williams](https://hamishw.com)' open-source portfolio template.

## Install & run

Requires Node.js `18.0.0` or higher and npm `8.6.0` or higher. Install dependencies with:

```bash
npm install
```

Start a local dev server:

```bash
npm run dev
```

Create and serve a production build:

```bash
npm run build
npm run start
```

View the components storybook:

```bash
npm run storybook
```

## Tech stack

- **Framework:** Next.js 14 (Pages Router)
- **3D / graphics:** Three.js + three-stdlib
- **Animation:** Framer Motion
- **Content:** MDX (mdx-bundler)
- **Component workshop:** Storybook 6
